文生图

前置工作

当与大模型进行文字交互的时候，采用的是ChatModel来进行交互，依此类推与大模型进行图片上的交互，同样需要ImageModel来进行交互。

    @Bean
    public ImageModel imageModel() {
        return DashScopeImageModel.builder()
                .dashScopeApi(new DashScopeImageApi(apiKey))
                .defaultOptions(DashScopeImageOptions.builder()
                        .withHeight(200)
                        .withWidth(200)
                        .withModel("wanx2.1-t2i-turbo").build())
                .build();
    }

配置ImageModel的时候需要指定模型名称，在Spring AI Alibaba的1.0.0.2版本中只有wanx-v1模型的枚举，但是这个模型属于是比较老的，我们可以阿里百炼大平台的模型广场中来查找需要的模型。

这里我们选择的是wanx2.1-t2i-turbo这个模型，每个模型是有不同的计费规则的，在调用的时候要关注下这个信息。

编写代码

在Controller中编写实际的调用结果：

    /**
     * @param message 主题
     * @description: <a href="http://localhost:8623/chat/image?messag=黑白小狗">测试接口</a>
     **/
    @GetMapping("/image")
    public void image(@RequestParam("message") String message, HttpServletResponse httpServletResponse) {
        ImagePrompt request = new ImagePrompt(message);
        ImageResponse imageResponse = imageModel.call(request);
        ImageGeneration result = imageResponse.getResult();
        log.info("==========>>>>>>>>>> 生成结果：{}", JSON.toJSONString(imageResponse));
        if (result == null) {
            return;
        }
        Image output = result.getOutput();
        log.info("==========>>>>>>>>>> ：{}", JSON.toJSONString(output));
        String imageUrl = output.getUrl();
        InputStream inputStream = null;
        try {
            URL url = URI.create(imageUrl).toURL();
            inputStream = url.openStream();
            httpServletResponse.setContentType(MediaType.IMAGE_PNG_VALUE);
            httpServletResponse.getOutputStream().write(inputStream.readAllBytes());
            httpServletResponse.getOutputStream().flush();
        } catch (Exception e) {
            log.error("==========>>>>>>>>>> ：{}", e.getMessage(), e);
        } finally {
            if (inputStream != null) {
                try {
                    inputStream.close();
                } catch (IOException e) {
                    log.error("==========>>>>>>>>>> ：{}", e.getMessage(), e);
                }
            }
        }
    }

其他内容

在ImageModel中只有一个call()方法，它返回的类型是ImageResponse。

@FunctionalInterface
public interface ImageModel extends Model<ImagePrompt, ImageResponse> {
    ImageResponse call(ImagePrompt request);
}

文生音

前置工作

文生音的使用的是SpeechSynthesisModel（语音合成模型），在Spring AI Alibaba中：

    public enum DashScopeSpeechModel {

        SAMBERT_ZHICHU_V1("sambert-zhichu-v1"),

        COSYVOICE_V1("cosyvoice-v1");

    }

默认是包含以上两种模型， 如果需要更多的模型支持可以在百炼平台的模型广场中进行查找。

编写代码

需要在创建一个SpeechSynthesisModel的实例，用于与语言合成的Model进行交互。

    @Bean
    public SpeechSynthesisModel speechSynthesisModel() {
        return new DashScopeSpeechSynthesisModel(new DashScopeSpeechSynthesisApi(apiKey));
    }

编写Controller来进行测试

    /**
     * @param topic
     * @description: 文生音 测试地址 <a href="http://localhost:8623/chat/voice?topic=支付宝到账100万元">测试接口</a>
     **/
    @GetMapping("/voice")
    public String voice(@RequestParam("topic") String topic) {
        SpeechSynthesisOptions options = DashScopeSpeechSynthesisOptions.builder()
                .model("cosyvoice-v2")
                .voice("longxiaochun_v2")
                .build();
        SpeechSynthesisPrompt prompt = new SpeechSynthesisPrompt(topic, options);
        SpeechSynthesisResponse speechSynthesisResponse = speechSynthesisModel.call(prompt);
        log.info("==========>>>>>>>>>>  ：{}", JSON.toJSONString(speechSynthesisResponse));
        if (speechSynthesisResponse == null) {
            return "FAILED";
        }
        SpeechSynthesisResult result = speechSynthesisResponse.getResult();
        ByteBuffer byteBuffer = result.getOutput().getAudio();
        try (FileOutputStream fileOutputStream = new FileOutputStream("D:\\test.mp3")) {
            FileChannel channel = fileOutputStream.getChannel();
            int write = channel.write(byteBuffer);
            log.info("==========>>>>>>>>>> 写入内容大小：{}", write);
            return "SUCCESS";
        } catch (Exception e) {
            log.error("==========>>>>>>>>>> ：{}", e.getMessage(), e);
            return "FAILED";
        }
    }

在测试接口后，可以在指定的路径中打开生成的mp3文件，然后就可以听到message参数中的内容。
